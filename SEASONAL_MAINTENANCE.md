# Seasonal Maintenance Schedule (24 Tasks)

## SPRING (4 Tasks)
Post-winter recovery and preparation for warmer months.

### 1. Battery & Electrical Post-Winter Check
- Battery SoH trending analysis via VCDS
- Electrical load management review
- Charging system verification
- Alternator output confirmation
- **Cost Estimate:** €0-100 (diagnostic only)

### 2. Fuel System Spring Refresh
- Fuel injector cleaning activation
- Carbon deposit removal cycle
- Fuel filter inspection
- **Cost Estimate:** €50-150

### 3. Cooling System Inspection
- Coolant level and concentration check
- Thermostat verification
- Heater core flow test
- **Cost Estimate:** €0-200

### 4. Brake Inspection & Reset
- Brake pad wear assessment
- Brake fluid condition check
- ABS self-test
- **Cost Estimate:** €0-300

---

## SUMMER (6 Tasks)
Preparation for hot weather operation and high-mileage driving.

### 1. High-Heat Fluid Checks
Coolant, ATF, power steering fluid condition verification
- ATF level and color assessment
- Power steering fluid pressure check
- Coolant boiling point verification
- **Cost Estimate:** €50-200

### 2. AC Performance Verification
- Refrigerant pressure test
- Compressor operation check
- Air output temperature measurement
- **Cost Estimate:** €0-150

### 3. Lighting & Visibility Check
- All exterior lights functional test
- Headlight beam alignment
- Windshield wiper blade condition
- **Cost Estimate:** €0-100

### 4. Performance Driving Preparation
- Brake fluid boiling point check
- Suspension geometry verification
- Tire pressure optimization for performance
- **Cost Estimate:** €0-150

### 5. Summer Tire Care
- Tire condition and tread depth assessment
- Tire pressure adjustment for heat
- Load rating verification
- **Cost Estimate:** €0-50

### 6. Suspension Safety Check
- Shock absorber damping test
- Suspension geometry inspection
- Anti-roll bar link condition
- **Cost Estimate:** €0-300

---

## FALL (6 Tasks)
Preparation for winter transition.

### 1. Pre-Winter Battery SoH Check
- Battery health state analysis
- Cold cranking amperage verification
- Battery registration update if needed
- **Cost Estimate:** €0-150 (battery €80-150 if replacement needed)

### 2. Brake System Flush & Pad Replacement
- Complete brake system fluid flush
- Brake pad replacement and bedding
- Rotor inspection and resurfacing if needed
- **Cost Estimate:** €200-400

### 3. Winter Tire Pressure Calibration
- TPMS recalibration for winter pressures
- Tire sensor battery check
- Pressure monitoring activation
- **Cost Estimate:** €0 (DIY with VCDS)

### 4. Fluid Service & Oil Grade Change
- Oil change with appropriate winter grade
- Filter replacement
- Fluid level top-ups across all systems
- **Cost Estimate:** €100-200

### 5. Wiper Blade & Washer Fluid Prep
- Winter-grade wiper blade installation
- Washer fluid level and winterization
- Wiper motor and linkage inspection
- **Cost Estimate:** €30-80

### 6. Brake System Deep Inspection
- ABS full system test
- Brake booster integrity check
- Caliper piston freedom verification
- **Cost Estimate:** €50-200

---

## WINTER (8 Tasks)
Cold weather operation and snow/ice driving preparation.

### 1. Cold-Start Performance Monitoring
- Cold-start fuel enrichment verification
- Glow plug system check (if diesel)
- Cold-start RPM targeting confirmation
- **Cost Estimate:** €0-100

### 2. Road Salt & Corrosion Prevention
- Undercarriage inspection
- Drain plug condition check
- Corrosion prevention fluid application
- **Cost Estimate:** €50-150

### 3. Traction Control & ABS Testing
- ABS activation and brake pressure verification
- Traction control response test
- Winter stability mode confirmation
- **Cost Estimate:** €0 (diagnostic only)

### 4. Cabin Humidity & Defogging
- Heating system output verification
- Cabin air recirculation function
- Humidity control system test
- **Cost Estimate:** €0-100

### 5. Battery Voltage Monitoring
- Cold weather voltage performance check
- Charging system winter output verification
- Battery heater functionality (if equipped)
- **Cost Estimate:** €0-150

### 6. Electrical Load Management
- Starting system current draw measurement
- Alternator capacity verification under load
- Parasitic drain check
- **Cost Estimate:** €0-100

### 7. Window Fogging Prevention
- Defroster operation verification
- Cabin air filter replacement if needed
- Humidity sensor calibration
- **Cost Estimate:** €30-100

### 8. Winter Tire Maintenance
- Tire condition and tread depth verification
- Studded tire rotation (if applicable)
- Winter tire pressure adjustment
- **Cost Estimate:** €0-50
